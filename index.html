kfkit

Open-source tools for running Apache Kafka® in production.

Small, focused tools that lean on a Kafka cluster you already operate instead of asking you to run something new alongside it. A broker that is already the durable, ordered log at the centre of your system can answer more questions than it usually gets asked.

Projects

kfklease

Distributed leases and leader election derived from a compacted topic, with a KEDA external scaler that keeps a workload running in one cluster at a time and fails it over when that cluster goes away. Go library, a container image and a Helm chart.
